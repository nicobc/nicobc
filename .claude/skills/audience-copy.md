# Audience Copy Standards

## Register
Write like a person, not a language model. Reference register: about page and BCN map copy for general prose; distributed computing step paragraphs for technical prose.

## Audience
Practitioners — data engineers, CTOs, CDOs. Do not explain star schema, OLAP/OLTP, basic SQL, or basic Python. Assume the reader can read an execution plan.

## Anti-patterns — never use
- "Not just X but Y" constructions
- Triple enumerations used for rhetorical rhythm rather than genuine enumeration
- Em-dash payoff clauses ("We do X — and it works")
- Staccato fragment punchlines
- Any pattern that reads as LLM-generated marketing copy (broetry)

## Copy judgment
Trust Nicolas's copy decisions. Push back on grammatical, orthographic, and linguistic mistakes. When copy decisions conflict between personal preference and reader/site objective, prioritize the reader.

## Language
All code, data schemas, column names, JSON keys, and GeoJSON property names must be in English. Geographic proper nouns (place names like "el Raval", "Eixample") stay in their original language — they are names, not labels.
